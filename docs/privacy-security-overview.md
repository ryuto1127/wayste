# Recycling Buddy Kiosk — プライバシー・セキュリティ概要

## 1. システムの仕組み

- ゴミ箱付近に設置した**下向きカメラ**で、手に持ったゴミの種類をAIが判定し、正しい分別先を画面に表示します。
- カメラは**真下のみ**を撮影するため、利用者の顔や体は映りません。
- AI推論はすべて**ブラウザ内**で完結します。映像フレームが外部のAIサービスに送信されることはありません。

## 2. プライバシー保護

| 項目 | 対応 |
|------|------|
| AI推論 | **ブラウザ内で完結** — 映像フレームは外部のAIサービスに送信されません |
| 個人情報の収集 | **なし** — 氏名・顔・ID等の個人を特定できる情報は収集・保存しません |
| 顔検出による保護 | ブラウザ内の顔検出AI（BlazeFace）がフレームに顔を検知した場合、そのフレームの保存を自動的にブロックします。顔検出AIが読み込めなかった場合も、安全側に倒して保存をブロックします |
| 精度改善用の画像保存 | 顔が映っていないフレームに限り、分類精度の改善を目的としてサーバーに画像を保存することがあります。保存された画像は**90日後に自動削除**されます |
| 運用ログ | 分類結果（ゴミの種類・分別先・信頼度・タイムスタンプ）がサーバーに記録されます。個人を特定できる情報は含まれません |

## 3. セキュリティ対策

- 通信はすべて**HTTPS**で暗号化されています。
- 保存された画像は**非公開ストレージ**に保管され、認証なしではアクセスできません。
- 管理画面はパスワード認証（4時間で自動失効）で保護されており、一般利用者はアクセスできません。
- APIへの過剰なリクエストは**レート制限**により自動的にブロックされます。

## 4. 実験終了時の対応

- 機器（カメラ・ディスプレイ）を撤去します。
- サーバー上の画像・ログデータを完全に削除します。
