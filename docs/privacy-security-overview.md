# Recycling Buddy Kiosk — プライバシー・セキュリティ概要

## 1. システムの仕組み

- ゴミ箱付近に設置した**下向きカメラ**で、手に持ったゴミの種類をAIが判定し、正しい分別先を画面に表示します。
- カメラは**真下のみ**を撮影するため、利用者の顔や体は映りません。
- AI推論はすべて**ブラウザ内**で完結します。映像フレームが外部のAIサービスに送信されることはありません。

## 2. プライバシー保護

| 項目 | 対応 |
|------|------|
| AI推論 | **ブラウザ内で完結** — 映像フレームは外部のAIサービスに送信されません |
| 個人情報の収集 | **なし** — 氏名・顔・ID等の個人を特定できる情報は収集・保存しません |
| 顔検出による保護 | ブラウザ内の顔検出AI（BlazeFace）がフレームに顔を検知した場合、そのフレームの保存を自動的にブロックします。顔検出AIが読み込めなかった場合も、安全側に倒して保存をブロックします |
| 精度改善用の画像保存 | 顔が映っていないフレームに限り、分類精度の改善を目的としてサーバーに画像を保存することがあります。保存された画像は**90日後に自動削除**されます |
| 運用ログ | 分類結果（ゴミの種類・分別先・信頼度・タイムスタンプ）がサーバーに記録されます。個人を特定できる情報は含まれません |

### 保存期間の根拠

画像の保持期間を **90日** としている理由:

- **用途**: 分類AIの誤判定ケースを確認し、モデルの再学習データとして活用するため
- **期間の妥当性**: 利用パターンの季節変動（同一月内の揺らぎ）を1サイクル観測するのに十分、かつ個人情報保護法の「利用目的の達成に必要な範囲」を逸脱しない範囲として設定
- **期間後**: 自動削除ジョブ（毎日 03:00 UTC）が対象画像を Vercel Blob から物理削除します
- **派生物**: 再学習に使用済みの画像はモデル改善後も匿名の訓練データとして別ファイル（個人特定不可能な形式）に変換され、元画像は削除されます

## 3. セキュリティ対策

- 通信はすべて**HTTPS**で暗号化されています（HSTS により2年間強制）。
- 保存された画像は**非公開ストレージ**に保管され、認証なしではアクセスできません。
- 管理画面はパスワード認証（4時間で自動失効）で保護されており、一般利用者はアクセスできません。
- キオスク端末からの API 呼び出しには個別トークン認証が必要です。
- APIへの過剰なリクエストは**レート制限**により自動的にブロックされます。
- 1日あたりの分類 API 呼び出し回数に**日次予算上限**を設定しており、クレデンシャル漏洩時でもコスト暴走を防止します。
- ログインイベント（成功・失敗・キオスク端末のアンロック）は**監査ログ**に記録され、不正アクセス時に追跡可能です。
- 依存パッケージの脆弱性は **GitHub Dependabot** による週次スキャンで自動検出します。

## 4. 利用者からのデータ削除依頼

万が一、誤って画像に顔が映り込んだ場合等、本システムに保存されたデータの削除をご希望の方は、以下の窓口までご連絡ください。

- **連絡先**: （設置時に記載）運用担当者のメールアドレス
- **提供情報**: 利用日時・利用場所（どのキオスク）・本人確認のための連絡先
- **対応**: 受付から7営業日以内に該当画像を特定・削除し、完了報告をお返しします
- **対応範囲**: Vercel Blob 上の画像ファイル、および該当する分類ログエントリ

※ 本システムは**画像に顔が映らないよう二重の顔検出ゲート**（クライアント側 + サーバー側）を設けているため、削除対象となる画像が保存される可能性は極めて低い設計となっています。

## 5. 実験終了時の対応

- 機器（カメラ・ディスプレイ）を撤去します。
- サーバー上の画像・ログデータを完全に削除します。
- 監査ログも同時に削除します。
